
Create a game for iOS using common lisp lispnik/objc lispnik/asdf-ios-app etc. The game consists of a queue of colored ant boxes. Each ant box has a count. The queue of ant boxes files up as deployment slots become avialabloe. e.g. the queue might be 3 wide and the deployment slots might be same width, or wider. When the user taps on an antbox at the top of the queue, it moves to an open deployment slot.

Above the deployment row are the ant resources. Ant resources are colored blocks on plate, set out in a grid and usually made into a colorful, pixelated picture of cubes. When an ant box is deployed, ants leave the box and seek out a coloroed cube of the same color as the ant (and its ant box) from the grid if it is accessible. If no cubes are accessible, then ants do not leave the box.

Once the ant collects a cube, it travels with it to a hole and jumps down it. The count on the deployed ant box decreases by one every time an ant escapes with a cube. When the deployed ant box count reaches zero, it disappears from the deployment row and its space is made available to the use for additioanl deploys.

The round ends when all the cubes are gone.

Depending on the order deployments the player took, it's possible for no deployed house to have ants that can reach anything. When this happens the player loses and the round can be restarted.
